261: ### Return Types
262: 
263: Custom endpoints can return:
264: 
265: 1. **Model Instance** - Returns full object as JSON with `$schema` and `$id` metadata (via `.model_response()`)
266: 2. **List of Models** - Returns array of objects, each with `$schema` and `$id`
267: 3. **dict** - Returns custom JSON structure (no automatic metadata)
268: 4. **str** - Returns plain string (wrapped in JSON)
269: 5. **None** - Returns null
270: 
271: When a custom endpoint returns a model instance, the route handler calls `.model_response()` to inject `$schema` and `$id` metadata into the response. This runs the dump pipeline (`proto_dump.run_pipeline()`), which is extensible via `@dump_extension`.
272: 
273: ### Examples
274: 
275: #### Return Model Instance
276: 
277: **Backend**:
278: ```python

454: ## Streaming Endpoints
455: 
456: Custom methods can stream progressive results to the client via Server-Sent Events (SSE). Mark the route with `stream=True` and use an async generator:
457: 
458: ### Backend
459: 
460: ```python
461: @expose_route('/generate', methods=['POST'], stream=True, access=AUTHENTICATED)
462: async def generate(self, prompt: str = ''):
463:     for i in range(10):
464:         await asyncio.sleep(0.1)
465:         yield {'chunk': f'Processing step {i}'}
466: ```
467: 
468: ### Frontend (SSE)
469: 
470: ```javascript
471: const handle = HTTP.stream('/products/1/generate', { prompt: 'hello' },
472:     (chunk) => document.body.append(chunk.chunk),  // progressive output
473:     (data)  => console.log('Stream complete'),
474:     (err)   => console.error('Stream error:', err),
475: );
476: 
477: // Cancel mid-stream:
478: handle.cancel();
479: ```
480: 
481: ### SSE Wire Format
482: 
483: ```
484: event: chunk
485: data: {"chunk": "Processing step 0"}
486: 
487: event: chunk
488: data: {"chunk": "Processing step 1"}
489: 
490: event: done
491: data: {}
492: ```
493: 
494: ### Component
495: 
496: Use `<ntx-stream>` instead of `<ntx-method>` for streaming methods:
497: 
498: ```html
499: <ntx-stream model="Product" uuid="1" method="generate" label="Generate"></ntx-stream>
500: ```
501: 
502: ### Schema Discovery
503: 
504: Streaming methods are discoverable via the schema. The method entry includes `"stream": true`:
505: 
506: ```json
507: {
508:   "methods": {
509:     "generate": {
510:       "route": "/generate",
511:       "methods": ["POST"],
512:       "stream": true,
513:       "parameters": { "prompt": { "type": "string" } }
514:     }
515:   }
516: }
517: ```

675: ### 6. Toggle Actions (Like/Favorite)
676: 
677: Toggle endpoints create or delete a child record and replace the parent
678: `list[T]` collection. Empty body allowed — no payload needed.
679: 
680: ```python
681: @expose_route('/favorite', methods=['POST'], access=AUTHENTICATED)
682: def favorite(self, user: User = None) -> str:
683:     """Toggle — create if not favorited, remove if already favorited."""
684:     existing = next((like for like in self.favorites if like.user == user.id), None)
685:     if existing:
686:         Like.delete(existing.id)
687:         type(self).update(self.id, {'favorites': [f for f in self.favorites if f.id != existing.id]})
688:         return json.dumps({"action": "unfavorited"})
689:     else:
690:         saved = Like.create(Like(user=user.id))
691:         type(self).update(self.id, {'favorites': [*self.favorites, saved]})
692:         return json.dumps({"action": "favorited"})
693: ```
694: 
695: **Frontend**:
696: ```javascript
697: // POST /products/1/favorite — empty body
698: const result = await fetch('/products/1/favorite', {
699:   method: 'POST',
700:   headers: {
701:     'Content-Type': 'application/json',
702:     'x-access-token': jwtToken
703:   },
704:   body: JSON.stringify({})
705: }).then(r => r.json());
706: 
707: console.log(result.action); // "favorited" or "unfavorited"
708: ```

836: 
837: ### Backend Endpoints
838: 
839: ```python
840: class User(ProtoModel):
841:     __storable__ = True
842:     __tablename__ = 'users'
843:     
844:     email: str
845:     password_hash: str
846:     
847:     @staticmethod
848:     @expose_route('/register', methods=['POST'])
849:     def register(email: str, password: str) -> dict:
850:         # Validate email uniqueness
851:         users = User.list()
852:         if any(u.email == email for u in users):
853:             raise ValueError("Email already registered")
854:         
855:         # Create user
856:         user = User.create(User(
857:             email=email,
858:             password_hash=hash_password(password)
859:         ))
860:         
861:         return {"user_id": user.id, "email": user.email}
862:     
863:     @staticmethod
864:     @expose_route('/login', methods=['POST'])
865:     def login(email: str, password: str) -> dict:
866:         users = User.list()
867:         user = next((u for u in users if u.email == email), None)
868:         
869:         if not user or not verify_password(password, user.password_hash):
870:             raise ValueError("Invalid credentials")
871:         
872:         token = create_token(user.id)
873:         return {
874:             "token": token,
875:             "user_id": user.id,
876:             "email": user.email
877:         }
878:     
879:     @expose_route('/change-password', methods=['POST'])
880:     def change_password(self, old_password: str, new_password: str) -> dict:
881:         if not verify_password(old_password, self.password_hash):
882:             raise ValueError("Current password is incorrect")
883:         
884:         self.password_hash = hash_password(new_password)
885:         self.save()
886:         
887:         return {"message": "Password changed successfully"}
888: ```

987: ## Best Practices
988: 
989: ### 1. Always Handle Errors
990: 
991: ```javascript
992: async function callCustomEndpoint() {
993:   try {
994:     const response = await fetch('/resource/action', {
995:       method: 'POST',
996:       headers: { 'Content-Type': 'application/json' },
997:       body: JSON.stringify(params)
998:     });
999:     
1000:     if (!response.ok) {
1001:       const error = await response.json();
1002:       // Extract meaningful error message
1003:       const message = error.detail?.[0]?.error || 'Unknown error';
1004:       throw new Error(message);
1005:     }
1006:     
1007:     return await response.json();
1008:     
1009:   } catch (err) {
1010:     console.error('API Error:', err);
1011:     // Show user-friendly message
1012:     showErrorToUser(err.message);
1013:     return null;
1014:   }
1015: }
1016: ```
