407: ### Authenticated User Injection
408: Custom methods receive the authenticated user by declaring a `user` parameter:
409: ```python
410: @expose_route('/comment', methods=['POST'])
411: def comment(self, comment: Comment, user: User = None) -> str:
412:     comment.user_owner = user.id if user else 1
413:     ...
414: ```
415: The route layer's `_resolve_user()` resolves the type hint from the JWT token. The `user` param is never read from the request body.

417: ### Actor System
418: For full details, read `/workspace/docs/ACTORS.md` and `packages/n3tx-actors/docs/`.
419: 
420: **`fullmethod`/`fullproperty` descriptors** (in `n3tx_core/utils/descriptors.py`): Generic descriptors for unified class/instance dispatch. Used by both actors and agents.
421: 
422: **Actor base class** extends PydanticBaseModel via `ActorMeta` metaclass. `send()` three-case routing, `use()` interceptors, class + instance state.
423: 
424: **TX** is a dataclass message envelope: `reply()`, `error()`, `is_error`, `stream_chunk()`, `stream_end()`.
425: 
426: **Matrix** extends Actor: root actor, `has()`, adapter delegation, module-level `matrix` singleton.
427: 
428: **ActorProxy** wraps any class as a routable actor without MI.

430: ### ActorModel Pattern
431: ```python
432: from n3tx_actors.models.actor_model import ActorModel
433: 
434: class Product(ActorModel):
435:     __tablename__ = 'products'
436:     __storable__ = True
437:     ...
438: ```
439: One import change from ProtoModel. `ActorModel(Actor, ProtoModel)` is the bridge class. CRUD via `handler_crud()`, lifecycle events, generic handler fallback.
440: 
441: ### AgentMixin — Self-Aware Models
442: For full details, read `/workspace/docs/AGENTS.md` and `packages/n3tx-agents/docs/`.
443: 
444: `__agent__ = True` gives a model LLM-powered reasoning. Six `@fullmethod` methods: `ctx()`, `tools()`, `agentic()`, `run()`, `agentic_stream()`, `run_stream()`.
445: 
446: **Config cascade** (3-tier): `config.AGENT_DEFAULTS` < `__agent__` dict < `agentic()` kwargs.
447: 
448: **AgentMixin vs AgentActor**: AgentMixin derives config from model definition; AgentActor stores config in DB fields.
449: 
450: **Import ordering**: `n3tx_agents` (or `import n3tx_agents`) must be imported **before** any model with `__agent__ = True` is defined. `n3tx_agents.__init__` calls `register_mixin('__agent__', AgentMixin)` which populates `proto_model._mixin_registry`. If a model is defined before this call, the mixin is silently not injected.

452: ### Three Levels of N3TX
453: ```python
454: # Level 1 — ProtoModel + direct routes (no actors)
455: app = create_app(models=[Product], storage="sqlite:///app.db")
456: 
457: # Level 2 — ActorModel + direct routes (actor capabilities, same HTTP layer)
458: app = create_app(models=[Product], storage="sqlite:///app.db")
459: 
460: # Level 3 — ActorModel + NetworkAPI (full actor routing)
461: app = create_app(models=[Product], storage="sqlite:///app.db", routing='actor')
462: ```
463: 
464: ### Two-Tier Auth (Level 3)
465: - **Tier 1**: `auth_interceptor` on `NetworkAPI.request()` — fast gate at protocol boundary
466: - **Tier 2**: `ActorModel._authorize()` in `handler_crud()` — full ABAC with resource instance
467: 
468: Level 1/2 use `routes_fastapi.py`'s single-pass authorization.

18: ## Frontend Architecture (Vanilla JS Web Components)
19: 
20: The frontend is split across two packages:
21: - **n3tx-core** (`packages/n3tx-core/src/n3tx_core/static/`) — Non-visual JS runtime: messaging (Actor/TX/Matrix), entity system (NTT), abstract component bridge (Component), transport, utils
22: - **n3tx-ui** (`packages/n3tx-ui/src/n3tx_ui/static/`) — Visual layer: registered custom elements, base classes with visual behavior (NTTElement, ListElement), form generator, widgets, themes
23: 
24: At runtime, static files from both packages (plus n3tx-agents if installed) are merged into a single URL namespace by `_discover_static_dirs()` in `backend.py`. The browser doesn't know which package shipped each file.
25: 
26: ```
27: NTT.js (n3tx-core)    Core entity system. Bootstraps by fetching schema from backend.
28:   |
29:   +-- SCHEMA()         Receives schema, creates DynamicClass via prototype()
30:   +-- prototype()      Builds class with typed properties, methods, value getter
31:   |                    Value getter injects $schema (schema URL) and $id (instance URL)
32:   |
33:   v
34: ntx-list.js (n3tx-ui)   <ntx-list model="Product"> - fetches and renders entity list
35: ntx-item.js (n3tx-ui)    <ntx-item> - adaptive entity rendering (xs pill → xl page)
36: ntx-stream.js (n3tx-ui)  Extends ntx-method for streaming methods (SSE + progressive output)
37: form.js (n3tx-ui)        Formidable generator - builds forms from schema properties
38: ```
