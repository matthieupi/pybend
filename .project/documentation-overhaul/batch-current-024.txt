556:         """Verify password against hash"""

559:         return hash_obj.hex() == hash_hex

200: ## Optional: Add File Uploads
201: 
202: Install and import the optional `n3tx-files` package when your app needs user
203: files, documents, audio, generated artifacts, or other byte resources.
204: 
205: ```python
206: from n3tx_core.app import create_app
207: from n3tx_files import File, LocalFileStore, configure_file_store
208: 
209: configure_file_store(LocalFileStore('./file-blobs'))
210: 
211: app = create_app(
212:     models=[File],
213:     storage='sqlite:///app.db',
214: )
215: ```
216: 
217: Upload a file:
218: 
219: ```bash
220: curl -X POST http://localhost:5000/files/upload \
221:   -H "x-access-token: $TOKEN" \
222:   -F "upload=@./sample.txt;type=text/plain"
223: ```
224: 
225: Download it:
226: 
227: ```bash
228: curl http://localhost:5000/files/1/download -o sample.txt
229: ```
230: 
231: Use it in a method by annotating a parameter as `File`:
232: 
233: ```python
234: @expose_route('/process', methods=['POST'])
235: async def process(file: File) -> dict:
236:     local = await file.ensure_local()
237:     return {'path': local['path']}
238: ```
239: 
240: Then call the method with a file address:
241: 
242: ```json
243: {"file": "/File/1"}
244: ```
245: 
246: File metadata is stored in normal N3TX storage. Blob bytes are stored in the
247: configured `FileStore` provider and are served through explicit authenticated
248: download routes, not static file mounting.
