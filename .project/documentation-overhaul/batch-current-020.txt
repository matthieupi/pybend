724: 
725: **Module**: `n3tx_agents.mixin`
726: 
727: Injected into any model with `__agent__ = True` via `ProtoModel.__init_subclass__`. All methods use `@fullmethod` (unified class/instance dispatch).

729: #### `agentic(target, task: str, **kwargs) -> dict`
730: 
731: Policy layer. Resolves config via 3-tier cascade, delegates to `run()`.
732: 
733: | Parameter | Type | Description |
734: |-----------|------|-------------|
735: | `task` | `str` | The user task / query to execute |
736: | `prompt` | `str` | Override system prompt (kwarg) |

738: | `user` | `dict` | JWT user dict for auth context (kwarg) |
739: | `llm` | `str \| Model` | Override LLM model (kwarg) |
740: | `constraints` | `dict` | Override constraints (kwarg) |
741: | `message_history` | `list` | Previous messages for multi-turn (kwarg) |
742: | `result_type` | `type` | Pydantic model for structured output (kwarg) |
743: 
744: **Returns**: `{"answer": str, "usage": {"input_tokens", "output_tokens", "requests"}, "messages": list, "message_count": int}`
745: 
746: #### `run(target, task, prompt, tools, ...) -> dict`
747: 
748: Engine. No config resolution. Receives fully resolved params. Same return shape as `agentic()`.
749: 
750: #### `agentic_stream(target, task, **kwargs)` -> async generator
751: 
752: Streaming policy layer. Same config cascade as `agentic()`. Yields TX-aligned chunks.
753: 
754: #### `run_stream(target, task, prompt, tools, ...)` -> async generator
755: 
756: Streaming engine. Yields `{"name": "text"|"done"|"error", "data": {...}, "meta": {...}}`.

957: ### Local model collections
958: 
959: Owned child collections are declared directly on the parent model:
960: 
961: ```python
962: class Product(ProtoModel):
963:     __tablename__ = 'products'
964:     __storable__ = True
965: 
966:     comments: list[Comment] = Field(default=[])
967: ```
968: 
969: `list[T]` stores an ordered JSON list of local child ids and hydrates those ids
970: into self-describing child objects in responses. Updates replace the ordered
971: list; child records keep their own flat class-name CRUD routes.
972: 
973: For shared relationship data, prefer an explicit link model. `ManyToMany[T]` is
974: a legacy helper for existing shared-link cases rather than the default
975: relationship primitive.

24: │                   Network Adapter Layer                          │
25: │          (Protocol → TX → Matrix → TX → Protocol)               │
26: │  • NetworkAPI (HTTP)    • NetworkMCP (JSON-RPC 2.0)             │
27: │  • NetworkAP (ActivityPub)  • NetworkWebSocket (WS)             │
28: └────────────────────────────┬────────────────────────────────────┘

34: │  • Class + Instance actors  • Lifecycle events                  │
35: └────────┬───────────────────────────────────────┬────────────────┘

62: ### Optional File Capability (`n3tx-files`)
63: 
64: N3TX file handling is packaged as an optional capability, not as core blob
65: storage. Apps opt in by importing/registering `File` from `n3tx_files`:
66: 
67: ```python
68: from n3tx_files import File, LocalFileStore, configure_file_store
69: 
70: configure_file_store(LocalFileStore('./file-blobs'))
71: app = create_app(models=[File, Job], storage='sqlite:///app.db')
72: ```
73: 
74: `File(ActorModel)` is the single public primitive:
75: 
76: ```text
77: File metadata row       -> normal N3TX storage, schema, auth, actor tools
78: File bytes              -> FileStore provider (LocalFileStore by default)
79: Upload/download bytes   -> package-owned explicit routes, not static assets
80: File-typed method args  -> type-driven materialization via File.resolve()
81: ```
82: 
83: This preserves the framework boundary: core does not import `n3tx_files`, blob
84: bytes are not stored in SQLite, and dynamic user files are not served through the
85: static asset catch-all.

87: ## Core Components
88: 
89: ### 1. ProtoModel
90: 
91: **Location**: `models/proto_model.py`
92: 
93: The foundation of N3TX's model system. All models inherit from `ProtoModel`.
94: 
95: **Responsibilities**:
96: - Base class for all data models
97: - Schema generation and introspection
98: - Optional storage injection via `__storable__` flag
99: - Foreign key field transformation
100: - Method signature collection for API documentation
101: 
102: **Key Features**:
103: 
104: ```python
105: class ProtoModel(PydanticBaseModel):
106:     class Config:
107:         extra = 'allow'  # Allow $schema and $id to survive FastAPI validation
108:     
109:     # Automatic storage injection
110:     def __init_subclass__(cls, **kwargs):
111:         if cls.__storable__:
112:             # Inject StorableMixin
113:             cls.__bases__ = (StorableMixin,) + cls.__bases__
114:             # Transform Pydantic models to Ref
115:             # Register with storage backend
116:     
117:     # Schema generation via composable pipeline (proto_schema)
118:     @classmethod
119:     def schema(cls) -> Dict[str, Any]:
120:         # Runs proto_schema.run_pipeline(cls) — 8 composable stages:
121:         # base -> strip_hidden -> methods -> agent -> defs -> access -> ui -> metadata
122:         # Extensions add stages via @schema_extension
123:         # Returns complete JSON schema including:
124:         # - $schema (pointing to {API_URL}/Schema)
125:         # - $id (pointing to {API_URL}/{ClassName})
126:         # - Fields (from Pydantic)
127:         # - Methods (from @expose_route)
128:         # - Referenced models in $defs (each with $id)
129: 
130:     # Enriched serialization via composable pipeline (proto_dump)

131:     def model_response(self, **kwargs) -> dict:
132:         # Runs proto_dump.run_pipeline(self) — stages:
133:         # base -> relationships -> schema_url -> instance_url -> populate
134:         # Extensions add stages via @dump_extension
135:         # Injects:
136:         # - $schema: URL to model's JSON Schema
137:         # - $id: URL to this specific instance using the class-name API path
138: ```
139: 
140: **Design Decisions**:
141: - Uses `__init_subclass__` for automatic mixin injection
142: - Leverages Pydantic for validation and schema generation
143: - Separate `schema()` from `referenced_json_schema()` to avoid circular references
144: - Config `extra='allow'` permits `$schema` and `$id` metadata fields to pass through FastAPI response validation
145: - `model_response()` provides JSON-LD style self-describing responses via the composable dump pipeline (`proto_dump`)
146: 
147: **Route grammar** is additive and preserves the original API split:
148: 
149: ```text
150: /{tablename}/...       JSON data API and custom methods
151: /{ClassName}           schema endpoint
152: /{ClassName}/_         JSON collection mirror of /{tablename}
153: /{ClassName}/{id:int}  JSON read/update/delete mirror of /{tablename}/{id:int}
154: /{ClassName}/{id:int}/{method}
155:                        literal custom method mirror, no generic catch-all
156: /{ClassName}/@...      HTML/view shell entrypoints
157: #{ClassName}/@...      frontend hash-router view routes
158: ```
159: 
160: The `@` segment always means view/html/component routing. It never invokes a
161: method. Entity `$id` values use class-name routes while table-name routes remain
162: available as compatibility API paths.
163: 
164: ### 2. StorableMixin
165: 
166: **Location**: `models/storable_mixin.py`
167: 
168: Provides CRUD operations through dependency injection.
169: 
170: **Pattern**: Strategy Pattern (storage backend is injected)
171: 
172: ```python
173: class StorableMixin:
174:     storage: ClassVar[StorageInterface] = None  # Injected
175: 
176:     @classmethod
177:     def create(cls, data: Any) -> Any:
178:         return cls.storage.create(cls, data)
179: 
180:     @classmethod
181:     def list(cls, sql_filter=None, limit=None, offset=None):
182:         return cls.storage.list(cls, sql_filter=sql_filter, limit=limit, offset=offset)
183: 
184:     # ... other CRUD methods
185: ```
186: 
187: **Pagination**: When `limit` is provided, `list()` returns `{"data": [...], "meta": {"total", "limit", "offset", "has_more"}}`. When omitted, returns a plain list (backward compatible).
188: 
189: **Key Features**:
190: - Storage backend agnostic
191: - Automatic join model support
192: - Foreign key unwrapping before persistence
193: - Lazy loading optimization
194: - Optional pagination with total count

196: ### 3. AbstractStorage
197: 
198: **Location**: `storage/abstract_storage.py`
199: 
200: Interface for storage backends (Strategy Pattern).
201: 
202: ```python
203: class AbstractStorage(ABC):
204:     @abstractmethod
205:     def create_table(self, model_class: Type[Any]): pass
206:     
207:     @abstractmethod
208:     def create(self, model_class: Type[Any], data: Dict[str, Any]) -> Any: pass
209:     
210:     @abstractmethod
211:     def list(self, model_class: Type[Any]) -> List[Any]: pass
212:     
213:     # ... other CRUD operations
214: ```
215: 
216: **Implementations**:
217: 
218: #### SQLiteStorage
219: - Automatic schema migration
220: - Foreign key handling
221: - JSON TEXT serialization for embedded `dict`, primitive lists, `list[T]`, and
222:   `list[Ref[T]]`; local model collections store ordered child ids and hydrate
223:   to child objects. See [JSON Fields](JSON_FIELDS.md).
224: 
225: #### JSONStorage
226: - File-based storage
227: - Auto-incrementing IDs
228: - Human-readable format

230: ### 4. Ref Type
231: 
232: **Location**: `models/ref.py` (`utils/typer.py` remains a compatibility import surface)
233: 
234: Type-safe model/actor identity pointer with JSON Schema generation and local or
235: distributed address parsing.
236: 
237: ```python
238: class Ref(Generic[T]):
239:     def __init__(self, value: Optional[Any] = None):
240:         if isinstance(value, BaseModel):
241:             self.id = value.id
242:             self._model = value
243:         elif isinstance(value, int):
244:             self.id = value
245:             self._model = None
246:         elif isinstance(value, str):
247:             self.id = canonicalize_ref(value)
248:     
249:     # Custom Pydantic schema for OpenAPI
250:     @classmethod
251:     def __get_pydantic_json_schema__(cls, ...):
252:         # Outputs $schema and $id instead of the old __url__ and __type__
253:         return {
254:             "type": "$ref",
255:             "$ref": f"#/$defs/{target.__name__}"
256:         }
257: ```
258: 
259: **Purpose**:
260: - Maintains type safety in the model layer
