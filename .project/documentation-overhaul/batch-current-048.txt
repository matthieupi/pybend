1: # N3TXTX Quickstart
2: 
3: ## 1. Setup
4: 
5: Point the framework to your backend in `config.js`:
6: 
7: ```js
8: export const config = {
9:     API_URL: 'http://localhost:5000',
10:     // ...
11: };
12: ```
13: 
14: ## 2. Minimal Page
15: 
16: ```html
17: <!DOCTYPE html>
18: <html lang="en">
19: <head>
20:     <meta charset="UTF-8">
21:     <title>My App</title>
22:     <link rel="stylesheet" href="./dark-theme.css">
23: </head>
24: <body>
25: 
26:     <!-- Display a list of Products from the backend -->
27:     <ntx-list model="Product"></ntx-list>
28: 
29:     <script type="module">
30:         import { Matrix, matrix } from './core/Matrix.js';
31:         import { N3TX } from './core/N3TX.js';
32:         import { config } from './config.js';
33:         import './components/ntx-item.js';
34:         import './components/ntx-list.js';
35:     </script>
36: 
37: </body>
38: </html>
39: ```
40: 
41: That's it. The `<ntx-list>` component will:
42: 1. Fetch the schema from `GET /Product`
43: 2. Discover the CRUD endpoint from `__tablename__` (e.g. `/products`)
44: 3. Pull all records and render editable `<ntx-item>` cards
45: 
46: ## 3. Key Concepts
47: 
48: | Concept | What it is |
49: |---------|-----------|
50: | **Matrix** | The root actor — routes all messages between local actors and the backend |
51: | **N3TX** | Named Transfer Type — type registry (static) + entity base class (instance) |
52: | **DynClass** | DynamicClass — runtime-generated N3TX subclass per model (e.g. "Product"), holds schema and instances |
53: | **TX** | A message (transaction) flowing through the actor system |
54: | **Component** | Base class for web components — connects HTML elements to the actor system |
55: 
56: ## 4. Web Components
57: 
58: ### `<ntx-list>`
59: 
60: Displays all records for a model.
61: 
62: ```html
63: <ntx-list model="Product"></ntx-list>
64: ```
65: 
66: - `model` — the backend model name (must match the registered name, e.g. `Product`, `User`)
67: 
68: ### `<ntx-item>`
69: 
70: Displays a single record. Usually created automatically by `<ntx-list>`, but can be used standalone:
71: 
72: ```html
73: <ntx-item ref="Product/4"></ntx-item>
74: ```
75: 
76: - `ref` — the N3TX address (`ModelName/id`)
77: - Click the pencil icon to edit, click save to persist changes to the backend
78: 
79: ## 5. How It Works
80: 
81: ```
82: Browser                          Backend
83: -------                          -------
84: <ntx-list model="Product">
85:    |
86:    +- ATTACH --> N3TX (static)
87:    |              +- GET /Product -----------> Schema
88:    |              +- Creates DynClass "Product"
89:    |              +- GET /products -----------> [records]
90:    |              |
91:    |              +- DynClass.READ creates N3TX instances
92:    |                    (Product/1, Product/2, ...)
93:    |
94:    +- Renders <ntx-item ref="Product/1">
95:                    |
96:                    +- ATTACH --> N3TX --> DynClass --> N3TX instance
97:                    |              +- DESCRIBE --> Item
98:                    |
99:                    +- On save: UPDATE --> N3TX --> PUT /products/1
100: ```
