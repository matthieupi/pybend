## 🗺️ Current Architecture / Flow

### Working CPU-safe tracer bullet

```text
browser upload
  -> app /storage/files/upload proxy
  -> storage /files/upload owns File metadata + bytes
  -> app /Media/create-capture stores list[Ref[File]] + filenames
  -> Run.start()
  -> compute ComputePipeline.upload_to_splat
  -> ComputeTask.materialize files into ComputeRunPaths.uploads
  -> TestPipelineWorker writes canonical outputs
  -> Artifact.create_from_file publishes to storage
  -> Run.artifacts stores Ref[Artifact]
  -> run-detail renders artifact cards
```

### Current broken real-backend stream path

```text
Run.start()
  -> modules/app/services/compute_gateway.py
  -> urllib POST http://compute:7200/compute_pipeline/upload-to-splat
  -> response.read() buffers entire text/event-stream
  -> long-running real pipeline closes/interrupts stream read
  -> app sees IncompleteRead(0 bytes read)
  -> Run marked failed
```

### Desired N3TX-native remote streaming path

```text
Run.start()
  -> TX(name="upload_to_splat", source="app", target="n3tx://compute/ComputePipeline/0")
  -> Matrix/RemoteMatrix.stream(tx)
  -> HTTP SSE to compute generated streaming route
  -> parse remote SSE frames incrementally into TX chunks
  -> app forwards chunk.data as RunPipelineEvent
  -> browser receives progressive Run.start() stream
```

- Compute already exposes `ComputePipeline.upload_to_splat` with `@expose_route(..., stream=True)`.
- N3TX already has local `NetworkAdapter.stream()` and `NetworkAPI` SSE output.
- Missing primitive: `RemoteMatrix.stream()` or equivalent remote streaming adapter behavior.
- App bootstrap currently configures only storage remotes in `_storage_remotes()`; compute remotes need to be added if the app uses `RemoteMatrix` for compute.
