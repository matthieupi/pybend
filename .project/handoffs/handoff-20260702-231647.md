## 🗺️ Current Architecture / Flow

```text
Old relationship path (being removed)

Product.comments: ListRef[Comment]
  -> generate_join_model(Product, Comment)
  -> ProductComment table/model
  -> join_models registry
  -> /Product/{product_id}/Comment/{comment_id}
  -> href arrays

New relationship path (current direction)

Product.comments: list[Comment]
  -> Product row stores ordered comment ids as JSON TEXT
  -> Comment remains a flat first-class entity
  -> /Comment/{id} and /comments/{id}
  -> Product.model_response() emits hydrated object arrays
  -> child identity uses flat class-name $id: /Comment/{id}
```

Key implications:

- `list[T]` is now an owned ordered relationship field persisted on the parent row.
- Child entities still have independent storage, auth, lifecycle, and flat CRUD routes.
- Nested CRUD routes are removed; creation/attachment is done through model methods such as `Product.comment()` or explicit parent list updates.
- `populate` no longer creates `{"data": ..., "meta": ...}` wrappers for local `list[T]`; current tests are being rewritten toward hydrated arrays.

             if parent_cls is deleted_cls or not hasattr(parent_cls, 'list'):
