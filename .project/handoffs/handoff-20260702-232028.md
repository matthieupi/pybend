## 🗺️ Current Architecture / Flow

```text
Model annotation
  Product.comments: list[Comment]
          |
          v
SQLite parent row
  comments = JSON ordered local child ids, e.g. [1, 2, 9]
          |
          v
ProtoModel.hydrate_fk()
  batch-load Comment instances from ids
          |
          v
ProtoModel.model_response() / proto_dump
  Product response embeds shallow Comment model_response() objects
          |
          v
HTTP identity
  Product.comments[0].$id == http://localhost:5000/Comment/1
```

- `list[T]` is a local relationship primitive, not an href-array and not a generated join model.
- Parent membership lives on the parent JSON field; child rows remain first-class flat resources.
- `Ref[T]` currently still stores/serializes local refs, but local API-facing hrefs now use class-name identity.
- `Ref[T]` / `n3tx://` public removal is later-phase work and intentionally not completed here.

Representative framework code shape added in `proto_dump.py`:

```python
def base(instance, **kwargs) -> dict:
    dump_kwargs = dict(kwargs)
    seen = dump_kwargs.pop('_seen', None) or set()
    current_key = _identity_key(instance)
    seen = seen | {current_key}

    data = PydanticBaseModel.model_dump(instance, **dump_kwargs)
    _overlay_local_relationship_responses(instance, data, seen)
    return data
```
