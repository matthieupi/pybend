Create `apps/veille/static/components/ntx-grant-analyze.js` -- a StreamActor-based web component for per-grant admissibility analysis.

**Pattern:** Follow `ntx-run-panel.js` closely for structure, StreamActor usage, UPPERCASE handlers, and styling. This component is simpler: no run creation step, just load grant info + trigger analysis.

**Component structure:**

```javascript
import { StreamActor } from './StreamActor.js';
import { config } from '../config.js';
```

Class `NTXGrantAnalyze extends StreamActor(HTMLElement)`:

**Private state:**
- `#grantId = null` -- set from `grant-id` attribute or hash route
- `#grantData = null` -- loaded grant data for display
- `#els` -- shadow DOM element refs
- `#textBuf = ''`, `#textRendered = 0`, `#textTimer = null` -- text buffering (same pattern as ntx-run-panel)

**Observed attributes:** `['grant-id']`

**attributeChangedCallback:** parse `grant-id` as int, call `#loadGrant()` if connected.

**connectedCallback:** Build shadow DOM with:
- Panel header: "Grant Analysis" title + status badge (idle/analyzing/done/error)
- Grant info section (id="grant-info"): shows title, funder, current status, current score when grant data loads
- Controls: "Re-run Analysis" button (id="analyze-btn"), "Back to Grants" link (onclick sets `window.location.hash = ''`)
- Log container (id="log"): streaming output area (same structure as ntx-run-panel)
- Footer (id="footer"): token usage after completion

**`#loadGrant()` method:**
Fetch grant data to display context:
```javascript
async #loadGrant() {
    if (!this.#grantId) return;
    const token = localStorage.getItem('jwtToken');
    try {
        const resp = await fetch(`${config.API_URL}/grants/${this.#grantId}`, {
            headers: { 'x-access-token': token },
        });
        if (resp.ok) {
            this.#grantData = await resp.json();
            this.#renderGrantInfo();
        }
    } catch (e) { /* silent */ }
}
```

**`#renderGrantInfo()` method:**
Display grant title, funder, current status, and current score in the grant-info section. Show the admissibility_reasoning (truncated) if it exists.

**`#startAnalysis()` method:**
```javascript
async #startAnalysis() {
    if (!this.#grantId) return;
    this.#els.log.innerHTML = '';
    this.#els.footer.innerHTML = '';
    this.#textBuf = '';
    this.#textRendered = 0;
    this.#els.btn.disabled = true;
    this.#setStatus('analyzing');

    const token = localStorage.getItem('jwtToken');
    if (!token) {
        this.#addEntry('error', 'Not authenticated.');
        this.#setStatus('error');
        this.#els.btn.disabled = false;
        return;
    }

    this.#addEntry('info', `Analyzing grant #${this.#grantId}: ${this.#grantData?.title || ''}`);
    const url = `${config.API_URL}/grants/${this.#grantId}/analyze`;
    this.stream(url, {}, { 'x-access-token': token });
}
```

Note: `this.stream()` is inherited from StreamActor. It opens an SSE stream to the URL. The second arg is the POST body, the third is extra headers. Check the StreamActor.stream() signature in the codebase -- if it only takes (url, body), pass the token via the third arg if supported, or set it in localStorage where StreamActor reads it automatically. Look at how ntx-run-panel calls `this.stream()` -- it only passes `(url, payload)` with no explicit token header, meaning StreamActor reads the token from localStorage internally.

Corrected call: `this.stream(url, {});` (no explicit headers -- StreamActor handles auth).

**UPPERCASE TX handlers (same pattern as ntx-run-panel):**

- `THINKING(data, meta)`: Show thinking indicator. Same logic as ntx-run-panel.
- `TOOL_CALL(data, meta)`: Clear thinking, show tool call. Add friendly descriptions:
  - `organizations_list` -> "Reading organization profile"
  - `grants_update` -> "Saving analysis results"
  - fallback: show tool name + args
- `TOOL_RESULT(data, meta)`: Mark tool call complete (correlate by call_id). For grants_update results, show brief status update.
- `TEXT(data, meta)`: Append to text buffer, debounced render with marked.js (same pattern as ntx-run-panel).
- `DONE(data, meta)`: Flush text, show token usage in footer.
- `STREAM_END(data)`: Set status to 'done', re-enable button, reload grant info to show updated status/score.
- `STREAM_ERROR(err)`: Show error, set status to 'error', re-enable button.

**Helper methods** (copy from ntx-run-panel pattern):
- `#addEntry(type, html)` -- append log entry
- `#clearThinking()` -- remove thinking indicator
- `#renderText(entry)` -- render text buffer with optional marked.js
- `#flushText()` -- flush text buffer
- `#setStatus(status)` -- update status badge
- `#scrollToBottom()` -- auto-scroll log
- `#esc(text)` -- HTML escape

   ```javascript
   function handleRoute() {
       const hash = window.location.hash.replace('#', '') || '';
       const runPanel = document.getElementById('run-panel');
       const sourceList = document.getElementById('source-list');
       const uploadSection = document.getElementById('upload-section');
       const analyzePanel = document.getElementById('analyze-panel');

       // Hide all panels by default
       if (runPanel) runPanel.style.display = 'none';
       if (sourceList) sourceList.style.display = 'none';
       if (uploadSection) uploadSection.style.display = 'none';
       if (analyzePanel) analyzePanel.style.display = 'none';

       if (hash === 'runs') {
           if (runPanel) runPanel.style.display = 'block';
       } else if (hash.startsWith('analyze/')) {
           const grantId = hash.split('/')[1];
           if (analyzePanel && grantId) {
               analyzePanel.setAttribute('grant-id', grantId);
               analyzePanel.style.display = 'block';
           }
       } else {
           // Default view: sources + upload
           if (sourceList) sourceList.style.display = '';
           if (uploadSection) uploadSection.style.display = '';
       }
   }
   ```

   This adds a new route: `#analyze/{grant_id}` -- navigating to `#analyze/42` shows the analyze panel for grant 42.
